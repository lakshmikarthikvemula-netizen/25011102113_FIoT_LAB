# Bosch Sensortec BME280 SensorAPI

The three driver files are from Bosch Sensortec SensorAPI v3.5.1. The repository's license is included alongside the driver. The lab adapter uses the double-compensation configuration and the three-argument settings API. [Bosch Sensortec upstream repository](https://github.com/boschsensortec/BME280_SensorAPI)
